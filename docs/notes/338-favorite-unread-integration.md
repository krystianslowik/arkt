# Favorite unread integration test contract (#338)

Tests run on the main actor; synthetic title and favicon events are synchronous. No timers or per-frame work are added. Worst cases include empty titles, 0, 1 and 99+, minimum tile width, and light/dark flavors. Bounds and positive finite text sizes are checked; pixel rendering and contrast are not.

1. The Settings window uses the shared defaults-backed `AppSettings` (`AppSession.settings`), whose `resetToDefaults()` removes `Key.preferences` and notifies observers. The ShellUI settings test proposes `favoriteBadges` and `FavoriteBadgePreferences` there; add the keys to the reset list and existing reset coverage. Persist, reopen, and reset both switches independently. This is separate from the Core SQLite `SettingsStore` used for other app state.
2. The window-set test proposes `ShellWindowSet.bindFavoriteBadgeSettings(_:)` to bind the shared `AppSettings` once, initialize new windows, and propagate observer changes to all windows. Two windows retain different live Favorites; switches change without new title events. `AppSession` is an app target and cannot be imported into ShellKit: its composition and forwarding to this binding remain an App-level integration limit, not covered by this test.
3. The handoff test transfers the same populated engine tab through the existing `ShellWindowSet` route. It checks the badge, retained saved display title and the proposed read-only `liveFavoriteTitle(for:)` seam after populated and empty snapshots. The latter distinguishes replay of an empty title from absence of live state. Live events, empty titles, unload and removal also clear state. The proposed `configure(_:for:)` grid seam is the real item configuration path exposed internally so a reused item can be configured for a different node.
4. Preserve #822 hover deferral and #802 split close/menu callbacks in landing order. Reconcile #824 geometry and #832 favicon metadata/picker changes, then rerun hit testing, targeted updates and bounds tests. The tests exercise press, menu and close, favicon display, and an unrelated tile's hover and selection state.
5. Music indication (#117) has no Favorite grid seam yet. Live site title formats, music coexistence, pixel rendering and contrast are unverified. Live Calendar Join remains unplanned (OS-06).

These are test-first contracts with proposed missing APIs, not an observed red. On a supported build environment, first run the focused ShellUI and GUI tests and establish the intended missing-integration red; then implement and run the applicable full suites. Local parsing, diff and import checks do not establish test execution.
