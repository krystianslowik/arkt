# Arkt 0.1.0-preview.1

Arkt is a native macOS browser with a sidebar for Spaces, pinned tabs and Today. It runs the Chromium engine, so
sites and Chrome Web Store extensions work as they do in Chrome. This is the first preview: expect rough edges.

## Requirements

- A Mac with Apple silicon.
- macOS 15 or later.

## How to open it

The build is not signed or notarized, so macOS blocks the first open.

1. Unzip `Arkt-0.1.0-preview.1-arm64.zip` and move `Arkt.app` to `/Applications`.
2. Open it. In **System Settings > Privacy & Security**, click **Open Anyway** next to the message about Arkt.
   Control-click > Open does not work on macOS 15.
3. Alternatively, run `xattr -dr com.apple.quarantine /Applications/Arkt.app` in Terminal and open the app. If the
   warning is still on screen, click Done on it before you run the command (never Move to Trash).

## Good to know

- The first launch is slower than later ones while macOS checks the engine.
- macOS asks once for access to the Keychain item "Arkt Safe Storage". While builds are ad-hoc signed, the prompt
  returns after every update.
- Your data lives in `~/Library/Application Support/Arkt`.
- Crash reports are opt-in and sent by hand. Arkt sends nothing on its own.

## What is in it

- Spaces, Favorites, pinned tabs and folders
- Split View
- Peek and Little Arkt
- The archive
- Themes
- Native dialogs and permission prompts
- Chrome extensions from the Chrome Web Store

## What is not in it yet

- Auto-update
- Importing beyond Spaces and tabs
- The Downloads UI
- Incognito
- Link routing
- 1Password
- The command bar redesign
