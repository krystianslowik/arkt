Draft notes for an unpublished alpha. No download is available yet. Release title on GitHub: "First light".

Arkt is a native macOS browser with a sidebar for Spaces, pinned tabs and Today. It runs the Chromium engine, so
sites and Chrome Web Store extensions work as they do in Chrome. This is the first alpha: Arkt is usable now, and
parts of it are unfinished.

- **Your Arc sidebar comes across** Spaces, Favorites, pinned tabs, folders and Today, in one import.
- **Spaces** each with its own theme, pinned tabs and folders.
- **The command bar** finds open tabs, folders and extensions, opens addresses and searches the web.
- **Split View** keeps two pages in one window.
- **Chrome extensions** from the Chrome Web Store work as they do in Chrome.
- **Peek, Little Arkt and Downloads** are in, with native dialogs and permission prompts.
- **Still to come** a history list, search suggestions, auto-update, Incognito with its own cookies, link routing and sync.

## Requirements

A Mac with Apple silicon and macOS 15 or later.

## How to open it

The build is not signed with a Developer ID or notarized, so macOS blocks the first open.

1. Open `Arkt-0.1.0-alpha.1-arm64.dmg` and drag Arkt to Applications.
2. Open it. In **System Settings > Privacy & Security**, click **Open Anyway** next to the message about Arkt.
   Control-click > Open does not work on macOS 15.
3. Alternatively, run `xattr -dr com.apple.quarantine /Applications/Arkt.app` in Terminal and open the app. If the
   warning is still on screen, click Done on it before you run the command (never Move to Trash).

## Good to know

The first launch is slower than later ones while macOS checks the engine. macOS asks once for access to the Keychain
item "Arkt Safe Storage"; while builds are ad-hoc signed, the prompt returns after every update. Your data lives in
`~/Library/Application Support/Arkt`. To undo a blocked site permission, type `chrome://settings/content` in the
command bar (Cmd-T or Cmd-L). Crash reports are opt-in and sent by hand: Arkt sends nothing on its own.

There is no history list yet: the Library's History section and the command bar's History group fill in with a later
alpha (#631).
