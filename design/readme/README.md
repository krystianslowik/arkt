# README interface previews

These are unchanged copies of approved captures from Arkt's interactive HTML design prototypes. They show design
intent, not screenshots of the native app or a record of implemented features. Each preview has a light and dark
variant, selected in the repository README with a `picture` element.

| Copied files in `screens/` | Original path under `design/` |
|---|---|
| `peek-open-{dark,light}.png` | `peek/screens/peek-open-{dark,light}.png` |
| `peek-split-{dark,light}.png` | `peek/screens/peek-split-{dark,light}.png` |
| `la-idle-{dark,light}.png` | `little-arkt/screens/la-idle-{dark,light}.png` |
| `advanced-{dark,light}.png` | `settings/screens/advanced-{dark,light}.png` |

The images were copied without cropping, recoloring or other modification. Their original prototype directories
may live on a separate design branch.

## Particle mark

`particle-mark.png` and `particle-mark.svg` are the approved 360 × 360 transparent particle mark, with no text or
background. Particle positions and RGB colors are sampled from the approved `01-mustard-on-white.png`, following
the website's particle approach.

The SVG is an editable particle composition, not a vector master of the logo.
