# Hybrid (replaced by the grouped bar, #988)

The approved design from #112: a glass bar with filter pills, a 300 pt preview column that widens the bar, a hint strip
and a mustard selection tick. The maintainer found it overengineered ("we need simple, fast, reliable") and replaced
it with the grouped bar in `../../README.md`. Kept for history only; do not build it. Open `prototype/hybrid-*.html`;
renders are in `screens/`.
