## Colors

| Token | Hex | Use |
|---|---|---|
| Mustard | `#E9B520` | Accent. Fills, the mark, highlights |
| Mustard highlight | `#F3CA3D` | Lighter accent, hover and fold highlight |
| Mustard shade | `#DCA319` | Pressed accent |
| Fold shadow | `#A96E12` | Belongs to the artwork; decorative only |
| Porcelain | `#FAF9F5` | Light surface |
| Graphite | `#202321` | Dark surface and text on mustard |

Mustard is a fill color, not a text color: it does not reach readable contrast as text on porcelain or white. Put
graphite text on mustard, and use mustard text only on graphite.

## Usage rules

- Write the name in lowercase: `arkt`. Use the supplied wordmark for lockups instead of typesetting it.
- Scale the mark proportionally. Do not redraw, recolor, rotate, outline or add gradients, bevels or shadows to it.
- Keep clear space of at least a quarter of the icon width around an isolated icon.
- One focal point per composition, generous empty space, porcelain or graphite as the main field.
- Descriptor copy: "A native macOS browser." Keep feature, performance and release claims out of graphics until they
  are true.

## Source fidelity

The mark is raster artwork. The icon is 456 x 456 px with its rounded plate baked in; the wordmark is 180 x 76 px.
Larger exports are interpolated and carry no extra detail. A vector or high-resolution master, a small-size variant
and a monochrome silhouette are not included yet.
