# Arkt macOS vector kit

Use the SVG in macOS/ for an app-icon canvas. Each master is 1024 × 1024, with an approximately 824 px tile and room for the outer shadow. The matching .icns includes ten standard and Retina representations. Mustard on white and mustard on graphite correspond to the supplied light and dark examples.

Use tile/ for a tightly cropped icon with transparent corners. Use backdrop/ for the corresponding opaque presentation crop. The wordmarks in wordmarks/ use separate outlined letters at the supplied 180 × 76 proportions.

The icon artwork was rebuilt from the supplied raster references. Each surface has a named Bézier outline in defs. The tile, lower loop, rear fold, upper return, crossbar, upper fold and front ribbon each have an editable paint group. The gradients supply the lighting and the Gaussian blurs supply the cast shadows. Changing a surface outline also updates its paint and clipping boundary.
